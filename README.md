# Hemoglobin Analysis iOS App

An iOS application for camera-based analysis and visualization of
oxygenated (oxyHb) and deoxygenated hemoglobin (deoxyHb).

This project was developed as part of my Bachelor's thesis in
Medical Engineering at Hochschule Koblenz.

## Features

- Real-time camera acquisition using AVFoundation
- Image processing and pixel-wise analysis
- ROI (Region of Interest) selection
- oxyHb and deoxyHb analysis
- False-color visualization / heatmaps
- Adjustable color scales
- Automatic and manual measurements
- Visualization of measurement history
- CSV export of measurement results

## Technologies

- Swift
- SwiftUI
- AVFoundation
- Core Image
- Core Graphics
- Apple Charts
- SIMD
